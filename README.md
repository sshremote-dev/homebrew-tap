# Homebrew tap for SSH Remote

One workspace for all your servers and projects: split terminals, Markdown, screens and files over the SSH you already have. See [sshremote.dev](https://sshremote.dev).

```sh
brew install --cask sshremote-dev/tap/sshremote   # macOS: the app, and sshremote on PATH
brew install sshremote-dev/tap/sshremote          # Linux
```

Written by `scripts/packages.py` of [sshremote](https://github.com/sshremote-dev/sshremote) with each release.
